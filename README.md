# Prospecta Aqui

Sistema de geração de leads para prospecção B2B. Permite buscar empresas por segmento e cidade, visualizar os dados (nome, telefone, site, endereço) e exportar os leads.

## Visão geral

O **Prospecta Aqui** é dividido em dois módulos:

- **Frontend** — Interface web construída com Next.js e ShadUI
- **Backend** — API REST que consulta empresas no Google Places API

## Como começar

Cada módulo possui seu próprio README com instruções detalhadas de instalação e configuração:

- [Frontend README](./frontend/README.md) — Instalação, configuração e execução do frontend
- [Backend README](./backend/README.md) — Instalação, configuração e execução do backend

## Requisitos gerais

- [Bun](https://bun.sh/) 1.0+
- Chave da Google Places API (para o backend)
